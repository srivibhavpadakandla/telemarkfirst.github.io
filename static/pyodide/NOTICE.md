# Pyodide runtime

This directory contains Pyodide 0.27.7, downloaded from the official `pyodide`
npm package. It provides CPython in WebAssembly for the local FLL Python
simulator. The files are redistributed under the Mozilla Public License 2.0,
included in `LICENSE`.

Source: https://github.com/pyodide/pyodide/tree/0.27.7

Runtime files: `pyodide.js`, `pyodide.asm.js`, `pyodide.asm.wasm`,
`python_stdlib.zip`, and `pyodide-lock.json`.

The Telemark Pybricks practice model is a separate educational simulation.
It does not include Pybricks firmware or run code on a physical SPIKE Prime Hub.
