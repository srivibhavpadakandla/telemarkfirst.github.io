# Lesson 4.3: Return a Result

A function can **return** a value to the caller for storage, comparison, or calculation. Printing only sends a value to the output panel, so it cannot replace a return when the main program needs the result. If one grid step represents two travel units, returning `steps * 2` can supply a route report.

## Calculate a route value

Define `double(number)` to return `number * 2`, call it with 6, and store the result in `answer` before printing. Predict the parameter and output, then repeat with 9. Use a value-returning call block for the assignment. A call that ignores its result cannot set `answer`.
