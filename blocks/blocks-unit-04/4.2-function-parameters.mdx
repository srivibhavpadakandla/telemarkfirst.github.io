# Lesson 4.2: Give Information to a Function

A **parameter** is a named input in a function definition, while an **argument** is the value supplied at a call. In `reportDistance(distance)`, calling with 4 gives `distance` the value 4 for that call. A later call with 9 uses 9 without changing the function body.

## Send different values

Define `reportDistance` with a `distance` parameter and print it inside the function. Call it with 4, 9, and a variable containing 12, predicting each output before using Step to inspect the parameter. Printing reports the value, while a movement function would also need a move command that uses it.
