# Lesson 4.1: Define and Call a Function

A **function** groups commands under a name, but its definition does not run those commands. A call runs them at a chosen point in the main program, which makes a routine such as `reportReady` reusable without copying its print blocks.

## Reuse one routine

Define `reportReady` to print `ready`, place two calls beneath the start block, and predict two output lines. Change the definition to print `robot ready`, then run again and use Step to trace from a call into the function and back. Java calls a function inside a class a method. Later robot code can use the same structure for motor actions.
