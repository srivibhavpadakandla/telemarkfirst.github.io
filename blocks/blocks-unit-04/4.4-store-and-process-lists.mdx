# Lesson 4.4: Store and Process a List

A **list** keeps values in order, letting a loop process route lengths or readings without separate blocks for every item. Blockly labels its first list position 1, while Java starts indexing at 0, so check the convention when selecting an item.

## Process planned distances

Store `[4, 7, 2]` in `segments` and print its first and third items, predicting 4 and 2. Set `total` to 0, then use a `for each` loop to print every item and add it to `total` before printing 13 after the loop. The list is a route plan, so a physical robot still needs feedback to compare planned and actual travel.
