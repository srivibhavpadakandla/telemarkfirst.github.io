# Lesson 4.5: Coding Challenge: Data Report

Build a report for three planned robot measurements using a list, a function call, and at least three printed results. The program must finish without an interpreter error. Choose one job for the function, such as labeling each item or returning its doubled value, and use a loop to pass the items so one changed value does not require rebuilding the report.

Test the first item, last item, and full list. The visible checks confirm the list, call, and output count. Compare the labels and values with your written plan because those meanings are yours to verify.
