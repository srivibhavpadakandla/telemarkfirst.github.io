# Lesson 0.1: The Workspace and Run Controls

Block programs in this workspace begin at `when program starts`. Commands connected beneath it will run when you press Run, while loose blocks will remain visible without affecting the result. Use a print block from the toolbox to test the connection and see where its connector fits.

## Compare two runs

Connect a print block beneath `when program starts`, enter `robot ready`, and press Run to check the output. Then disconnect the print block and run the program again, comparing the two results before reconnecting it.

## Inspect and save your program

After reconnecting the print block, run the program and use Step to replay the recorded instructions one at a time. If the output differs from your prediction, compare each replayed instruction with the expected result to locate the change. Download your workspace before using Reset, which will restore the starter program after confirmation, and use Import to load the version you saved.
