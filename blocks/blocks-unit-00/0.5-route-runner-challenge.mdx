# Lesson 0.5: Coding Challenge: Route Runner

Program the grid robot to finish at x = 2, y = 1 after exactly three movement steps, then print `done`. Starting from the field's initial position and direction, write the expected position after each movement before placing blocks. One valid route moves east twice, turns right, and moves south once.

Run the visible checks and use Step if the endpoint differs from your plan. Count grid steps rather than move blocks when checking the total, since one block can request several steps. Passing the challenge records all five lessons in this unit. Skipping it records only the challenge.
