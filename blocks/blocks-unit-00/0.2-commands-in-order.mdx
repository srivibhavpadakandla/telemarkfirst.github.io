# Lesson 0.2: Commands Run in Order

The order in which connected commands run is called a **sequence**, and that order determines the route a robot will take. A turn before a drive changes the direction of that drive, so rearranging the same blocks can change the final position.

## Build a route

The robot will start at `(0, 0)` facing east. Connect the following commands beneath `when program starts` and predict the final position before pressing Run:

1. Move forward 2 steps.
2. Turn right.
3. Move forward 1 step.
4. Print `done`.

The first drive will end at `(2, 0)`, and the right turn will make the second drive end at `(2, 1)` before `done` appears in the output. Move the turn block ahead of the first drive, predict the new endpoint, and run the revised program, using Step to check each movement against your prediction.

## Check output order

For a second test, connect three print blocks containing `first`, `second`, and `third` beneath the start block. Predict the output before running, then swap two blocks and run again to compare the printed order.
