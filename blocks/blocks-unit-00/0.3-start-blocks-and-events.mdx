# Lesson 0.3: Start Blocks and Events

An **event** starts a programmed response. On a robot, that could be a driver pressing Start, a button press, or a sensor reading crossing a threshold. The commands connected to the event form its **event handler**. In this workspace, Run starts only the stack beneath `when program starts`.

## Test the start connection

Connect a print block containing `started` below `when program starts`, and leave a second print block containing `loose` elsewhere in the workspace. Predict the output before running, then attach the loose block to the first print block and run again. Use Step to trace both connected commands and identify where execution begins.

A physical robot could start another handler from a button press. Describe the event and the commands it would trigger, keeping in mind that this workspace has no button event block.
