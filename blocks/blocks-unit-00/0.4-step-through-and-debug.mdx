# Lesson 0.4: Step Through and Debug a Program

**Debugging** starts with the first difference between what a program should do and what it actually does. A final position tells you where the route ended, but checking each step tells you which command changed it.

Plan a route from x = 0, y = 0, facing east: move 3, turn right, move 2, then print `done`. Record the expected position and direction after each command. The planned finish is x = 3, y = 2, facing south.

## Find the first wrong step

Build the route and use Step to compare each field state with your notes. Move the turn below the second move, predict the new endpoint, and run again to locate the first departure from the original plan. Restore the turn before repeating the test, changing one block at a time so each result has a clear cause.

On a physical robot, motor direction and wheel movement would also need checking. The grid exercise focuses on command order and values.
