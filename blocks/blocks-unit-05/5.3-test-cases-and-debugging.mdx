# Lesson 5.3: Test Cases and Debugging

A **test case** pairs an input with its expected result. For a threshold, test a common value, the exact boundary, and a value just below it, writing down each expected Boolean before running. When a test fails, use Step to inspect the first wrong input, comparison, loop boundary, argument, or return value, then change one cause and rerun.

## Check a threshold function

Create a function that returns `true` at 10 or above, then test 12, 10, and 9 for `true`, `true`, and `false`. Run the same inputs from a list. Change `>= 10` to `> 10` to see why the boundary test fails, then restore the operator. Real sensor trials will add variation that fixed values cannot show.
