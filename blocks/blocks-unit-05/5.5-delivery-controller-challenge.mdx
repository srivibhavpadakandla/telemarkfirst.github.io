# Lesson 5.5: Final Coding Challenge: Delivery Controller

Build a simulated delivery controller that stores a list, uses at least two named variables, calls a function, runs a loop, makes a decision, moves exactly six grid steps, and prints `ready`. Plan what the data represents and where the robot moves before placing blocks.

Test an ordinary input, the decision boundary, and a value that takes another branch. After the visible checks, use Step to locate the first state that differs from the plan. The checks confirm the required structures and movement count. Passing them records this unit, while skipping records only the challenge.
