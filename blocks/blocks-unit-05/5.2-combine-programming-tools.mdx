# Lesson 5.2: Combine State, Decisions, Loops, and Functions

A combined program uses each structure for a different job: variables retain state, conditions select actions, loops repeat work, functions group routines, and lists keep related values in order. Trace the main sequence first, entering each function call and recording the Boolean result and loop count as they occur.

## Process a mission list

Store `[2, 6, 9]` as planned values. Write a function that prints `keep` for a value of at least 5 and `check` otherwise, then call it for each list item in a loop. Increase `processed` on every repeat and predict the three labels and final count before running. Use Step at the first difference between your trace and the output.
