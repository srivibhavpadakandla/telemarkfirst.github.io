# Lesson 5.4: Read Blocks Beside Java-Shaped Code

Blocks and Java can express the same sequence, loop, and decision. Blocks use connections to show nesting, while Java uses typed statements, braces, and punctuation. This example starts a mission counter at 0, adds 2 for each of three tasks, and reports `ready` when the total reaches 6:

```java
int completedPoints = 0;
for (int task = 0; task < 3; task++) {
    completedPoints = completedPoints + 2;
}
if (completedPoints >= 6) {
    System.out.println("ready");
}
```

## Match the structures

Build the block version and trace `completedPoints` through 0, 2, 4, and 6. Match its assignment, loop, comparison, and print command to the Java lines, then change both versions so two tasks add 3 points each. This example uses ordinary Java syntax, with FTC SDK and hardware commands introduced later.
