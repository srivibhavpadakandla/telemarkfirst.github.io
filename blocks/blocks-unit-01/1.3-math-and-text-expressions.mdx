# Lesson 1.3: Math and Text Expressions

An **expression** calculates one value from other values. A route with segments of 3 and 4 steps has `3 + 4 = 7` planned steps, while `(3 + 4) * 2` evaluates to 14 because the addition happens inside the larger expression. Changing how the blocks nest changes the result.

## Calculate and label a plan

Build `(3 + 4) * 2`, store it in `plannedSteps`, and print the number. Join `planned steps: ` with the variable and print the labeled result, predicting `14` and `planned steps: 14` before running. This output checks the calculation, while a movement command would be needed to change the robot's route.
