# Lesson 1.1: Numbers, Text, and True or False

Robot programs use different values for different jobs: a **number** can represent distance or a reading, **text** can label a status report, and a **Boolean** records `true` or `false`. The number `8` and the text `"8"` may look alike in output, but adding 2 to the number gives 10 while joining `"8"` and `"2"` gives `"82"`.

## Compare the value types

Print `3`, `ready`, a Boolean, and the result of `3 > 2`, predicting all four outputs before running. Change the comparison to `3 > 5` and check how its Boolean result changes. A physical robot might display `ready` for a driver, while its measurements still need numeric values for calculations.
