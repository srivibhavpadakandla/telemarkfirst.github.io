# Lesson 1.5: Coding Challenge: Score Tracker

Build a program that stores a mission score, changes it through a calculation or `change by` block, and finishes by printing `12`. For one plan, set `score` to 4, add 3, and add 5. These numbers stand for three scoring actions rather than measurements from the field.

Run the checks and compare the stored value with the printed value. If they differ, inspect where the print block reads `score`. A single print block cannot pass because the challenge also checks for an assignment and a calculation or change operation.
