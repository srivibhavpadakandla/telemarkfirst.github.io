# Lesson 1.4: Inputs, Outputs, and Value Tracing

A program receives an **input**, keeps or changes values as state, and produces an **output** such as a report or commanded action. The workspace has no live distance sensor, so use a fixed test number for `distanceReading` and distinguish that assumed input from anything the program calculates.

## Record each change

Set `distanceReading` to 6 and `safeDistance` to 4, then print both. Change `distanceReading` to 2 and print it again. Before using Step, make a table with columns for instruction, distance, threshold, and output, then compare each row with the variable panel. The same tracing method will work when a real sensor replaces the fixed test value.
