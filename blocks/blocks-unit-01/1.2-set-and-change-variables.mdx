# Lesson 1.2: Create, Set, and Change Variables

A **variable** stores a named value during a run. For example, `completedTasks` could start at 0 and increase after each successful task, so later commands use its current value. **Set** replaces that value, **Change by** adds or subtracts from it, and **Get** reads it. Setting 2 and then adding 3 produces 5.

## Trace a changing score

Create `score`, set it to 4, and print it before changing it by 3 and printing it again. Change it by 5 for a final output of 12, then use Step to inspect the stored value after each assignment. A variable name alone is not a measurement: the program still needs to assign a sensor reading, calculation, or chosen constant.
