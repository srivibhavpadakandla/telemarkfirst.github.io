# Python Learning Resources

Use these optional Python resources if the ideas from Blocks make sense but typing code still takes practice. Learners who are comfortable with text code can continue directly to FTC Java.

These courses run outside Telemark, so their accounts and progress do not sync here. The first group is free and works in a browser.

## futurecoder

futurecoder provides free, open source exercises with focused debugging help. Its browser editor lets you write and run Python, inspect errors, and work through beginner problems.

[Start futurecoder](https://futurecoder.io/)

## Code Club Python

Code Club offers free project paths from the Raspberry Pi Foundation for learners who prefer building something as they practise. Its Python projects use variables, functions, and loops in visual and interactive work, with no local editor setup required.

[Open Code Club Python](https://codeclub.org/en/learn-to-code)

## CS50's Introduction to Programming with Python

CS50P is a longer course covering functions, variables, conditions, loops, testing, files, and object-oriented programming. Its free OpenCourseWare version works through a browser, and you can return to Java before finishing the whole course.

[Open CS50P](https://cs50.harvard.edu/python/)

## Programiz Python

Programiz offers free, topic-based lessons on Python fundamentals, control flow, functions, classes, and objects. Use its browser editor for small examples without local setup or an account.

[Open Programiz Python](https://www.programiz.com/python-programming)

## Python.org

Python.org maintains a beginner page and links to more learning material. Use it to look up language topics or find another tutorial when a specific question comes up.

[Open Python for Beginners](https://www.python.org/about/gettingstarted/)

## More Course Catalogs

The services below mix free and paid material. Check the access label before beginning a course.

## Codecademy

Codecademy has short interactive Python exercises and requires an account. Its catalog includes free material, while the full Learn Python 3 course currently requires a paid plan, so check the access label before starting.

[Browse Codecademy Python](https://www.codecademy.com/catalog/language/python)

[Read Codecademy's plan and pricing explanation](https://help.codecademy.com/hc/en-us/articles/360022052834-Price-of-Codecademy)

## CodeChef

CodeChef's beginner Python course teaches syntax through many small input and output problems. Some topics are free and others require CodeChef Pro, with exercises focused on exact results rather than visual projects.

[Open CodeChef Python](https://www.codechef.com/learn/course/python)

[Read the CodeChef access FAQ](https://www.codechef.com/faq)
