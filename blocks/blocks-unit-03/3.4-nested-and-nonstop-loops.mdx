# Lesson 3.4: Nested Loops and Programs That Do Not Stop

A **nested loop** runs its inner loop fully for every outer repeat. An outer count of 2 and inner count of 3 therefore run the inner body six times, which can represent two scan rows with three positions each. The loops count actions, while actual movement still requires drive and turn commands.

## Trace both levels

Print `scan` in an inner repeat of 3 inside an outer repeat of 2, and predict six output lines. Add movement inside the inner loop and a turn after it, then use Step to separate actions per position from actions per row. If the operation limit ends the run, inspect the repeat counts and any `while` condition before running again.
