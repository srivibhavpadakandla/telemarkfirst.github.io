# Lesson 3.2: Repeat While a Rule Is True

A `while` loop checks its condition before every repeat and stops when that condition becomes false. Use a changing counter to practise the control flow: if `count < 4` stays true because the program never changes `count`, the simulator will eventually stop at its operation limit.

## Trace the stopping rule

Set `count` to 0, then print and increase it by 1 while it remains below 4. Predict the output and final value before using Step to inspect each check. Move the change block after the loop for one run to see the safety message, then return it to the loop. A physical sensor wait also needs a timeout or stop control when the expected reading never arrives.
