# Lesson 3.3: Counting Loops and Loop Variables

A **counting loop** changes a variable through a planned range, which can label positions in a scan. From 1 through 4, it repeats four times. From 0 through 4, it repeats five, creating an **off-by-one error** if the route expected four moves.

## Label four positions

Create a loop with `position` from 1 through 4 by 1, printing its value and moving forward once on each repeat. Predict four output lines, four movement steps, and a final x position of 4. Change the range to 0 through 3 and use Step to compare the new labels with the same four field positions.
