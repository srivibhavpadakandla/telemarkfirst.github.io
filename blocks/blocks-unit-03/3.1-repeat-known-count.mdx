# Lesson 3.1: Repeat a Known Number of Times

A **fixed-count loop** repeats its inner commands a chosen number of times. Put one `move forward by 1` inside `repeat 4` to travel four grid steps without copying the movement block. Commands after the loop run once, and a loop with zero repeats skips its body.

## Count movements and reports

Build the four-step loop and predict its final field position. Print `step` inside the loop and `finished` after it, then check that the output contains four `step` lines and one `finished` line. Set the repeat count to zero for another run. The position should stay at the start. On a physical robot, a fixed count cannot correct wheel slip by itself.
