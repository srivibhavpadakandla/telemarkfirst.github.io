# Lesson 3.5: Coding Challenge: Grid Scanner

Create a route that ends at x = 4, y = 4 after exactly eight movement steps, using at least one loop and staying within the operation limit. One plan moves east four steps, turns right, and moves south four steps. Record the expected position after each section before building it.

Run the visible checks and inspect direction before the second movement section if the endpoint is wrong. Count actual grid steps, including those requested by a move block inside a loop, when checking the total. The grid measures program flow rather than physical path accuracy.
