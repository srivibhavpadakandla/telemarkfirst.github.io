# Lesson 2.4: Combine Rules with And, Or, and Not

Boolean operators combine rules: `and` needs both conditions, `or` accepts either one, and `not` reverses a Boolean result. An intake could require a weight below its limit and a ready attachment, while two accepted marker codes could be joined with `or`.

## Test combinations

Set `weight` to 8 and `attachmentReady` to true, then predict `weight < 10 and attachmentReady`. Test again with weight 12 and with readiness false, recording each input pair and result. Add text `A` or `B` as an accepted code, and use `not` on that test to report a rejected code. The entered values stand in for measurements and marker readings.
