# Lesson 2.3: Use Else and Else If

Use `else` for a second outcome and `else if` when several conditions need separate responses. The program checks from top to bottom and runs the first matching branch, leaving the final `else` for all remaining values. Put restrictive thresholds first: a reading of 50 would match `distanceReading >= 20` before reaching `distanceReading >= 40` if those branches were reversed.

## Classify a reading

Print `clear` at 40 or above, `caution` from 20 through 39, and `stop` below 20. Test 50, 30, 10, and the exact boundaries 40 and 20, recording which branch runs each time. The labels classify entered values, while a physical robot would also need calibrated readings and a tested action policy.
