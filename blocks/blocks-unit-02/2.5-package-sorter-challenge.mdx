# Lesson 2.5: Coding Challenge: Package Sorter

Write one acceptance rule for a package, then store a test value, compare it with a threshold, and use an `if` or `if else` block to print `accept` or `reject`. For an accepted input, `reject` must not appear in the same run.

Test below, at, and above the boundary before returning to an accepted value for the visible checks. Use Step to confirm the selected branch. The checks look for a comparison and a decision in the program, so judge the quality of the rule against the sentence you wrote rather than against a physical sorting result.
