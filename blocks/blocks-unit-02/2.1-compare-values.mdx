# Lesson 2.1: Compare Two Values

A **comparison** checks two values and produces `true` or `false`, which a robot program can use when a reading reaches a threshold. For `distanceReading >= 10`, values 10 and 11 pass while 9 fails. The operator `>` excludes 10, so the choice matters at the boundary.

## Test the boundary

Set `distanceReading` to 10 and predict the results of `distanceReading >= 10`, `distanceReading > 10`, and `distanceReading = 10` before printing them. Repeat with 9 and 11 to see which results change. These values are entered test data, so record that assumption when applying the rule to a real sensor.
