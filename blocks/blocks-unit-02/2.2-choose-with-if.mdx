# Lesson 2.2: Make a Choice with If

An `if` block runs its inner commands when its condition is true, then the program continues with commands connected below the complete block. That placement matters: a status report inside the branch is conditional, while a report after it runs either way.

## Test one decision

Set `distanceReading` to 6 and add an `if` that prints `obstacle near` when the value is below 8. Connect a second print block after the `if` for `check complete`, and predict both output lines. Change the reading to 10, run again, and use Step to see why only `check complete` remains. The fixed reading models a sensor rule without requiring a sensor on the grid.
