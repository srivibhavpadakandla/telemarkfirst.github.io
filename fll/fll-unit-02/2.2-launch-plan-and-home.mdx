# Lesson F2.2: Launch Marks and Home

The route from the last lesson depends on where the robot starts. This lesson uses two physical marks to give each launch the same position and heading, then checks whether a short route can return home. A repeated starting pose may make differences in the route easier to interpret.

## Worked example

`run_short_mission()` drives 250 mm, turns, makes a short side move, and reverses that side move. The final turn and reverse drive request a return to the original pose. This only works as a field route if the return path stays clear.

~~~python
def run_short_mission():
    robot.straight(250)
    robot.turn(90)
    robot.straight(50)
    robot.straight(-50)
    robot.turn(-90)
    robot.straight(-250)

run_short_mission()
~~~

## Simulator practice

A drawing of the outgoing and return segments can help you predict the final pose before running the code. In the simulator, compare that prediction with the blue home boundary. If the route misses, note which segment first differs from the drawing.

## On the robot

Two marks for the same chassis edges can make the physical launch position easier to repeat. Marking the final position after five starts may show whether the route ends in one area or spreads across the mat.

## Check and adjust

The launch notes should let another teammate place the robot the same way. If the five final positions vary, check the launch marks and alignment before changing the route.
