# Lesson F2.1: Python Functions and Parameters

We have used individual drive commands for each route. A function lets us name a move and call it with different distances. Here we will make one distance function and use it twice, so the distance at each call is easy to find. A parameter such as `distance_mm` also makes its unit clear to a teammate.

## Worked example

`drive_mm` takes a distance in millimeters and passes it to `robot.straight()`. The first call requests 200 mm. After the turn, the second call requests 50 mm without changing the function itself.

~~~python
def drive_mm(distance_mm):
    robot.straight(distance_mm)

drive_mm(200)
robot.turn(90)
drive_mm(50)
~~~

## Simulator practice

The starter has one drive and one turn command. Adding `drive_mm` from the example and calling it before and after the turn creates two segments to compare. Changing only one argument can show which segment that call controls.

## On the robot

A repeated drive or tool action may be easier to adjust in Pybricks Code when it has one named function. Two calls with different arguments can show whether the function gives the expected motion for both values.

## Check and adjust

The function definition should describe one action, while each call supplies the value for that action. If only one segment has the wrong distance, its argument is a useful first place to check.
