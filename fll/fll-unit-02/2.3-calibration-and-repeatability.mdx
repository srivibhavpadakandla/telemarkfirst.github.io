# Lesson F2.3: Calibration and Repeatability

One run near a target does not tell us whether the route repeats. This lesson compares several 500 mm drives so we can tell a consistent shortfall from variation between runs. A consistent offset may point to a wheel dimension; scattered endpoints may point to grip, launch alignment, or loose parts.

## Worked example

The constants give the DriveBase a wheel diameter and axle track in millimeters. `robot.straight(500)` then uses those values to estimate travel. The simulator can vary wheel calibration between profiles, while a physical test can help us decide whether the values fit the actual build.

~~~python
WHEEL_DIAMETER_MM = 56
AXLE_TRACK_MM = 112
robot = DriveBase(left_motor, right_motor,
                  wheel_diameter=WHEEL_DIAMETER_MM,
                  axle_track=AXLE_TRACK_MM)
robot.straight(500)
~~~

## Simulator practice

The simulator's calibration table shows how the same code ends under three wheel profiles. Comparing those endpoints after a 500 mm drive can reveal whether a route is sensitive to a small wheel difference. Repeating an unchanged run should give the same simulated result for each profile.

## On the robot

Wheel diameter and the spacing between wheel contact points are starting measurements for the real DriveBase. Five 500 mm trials with unchanged code can show whether the robot has a repeatable bias or run-to-run scatter.

## Check and adjust

The trial notes should separate a similar miss on every run from a miss that changes size or direction. A stable bias may justify a measured geometry adjustment; scatter calls for checking grip and loose parts first.
