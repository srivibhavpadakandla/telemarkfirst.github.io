# Lesson F2.3: Calibration and Repeatability

One successful trial does not show whether a route is repeatable. If several runs finish about 20 mm short, adjust a measured parameter. If errors vary, inspect grip, loose parts, launch alignment, and battery state before changing code. Keep the last reliable program while testing each change.

## Worked example

~~~python
WHEEL_DIAMETER_MM = 56
AXLE_TRACK_MM = 112
robot = DriveBase(left_motor, right_motor,
                  wheel_diameter=WHEEL_DIAMETER_MM,
                  axle_track=AXLE_TRACK_MM)
robot.straight(500)
~~~

## Simulator practice

Run the same 500 mm route three times. After each run, compare the automatic calibration profile table and record any endpoint differences.

## On the robot

Measure actual wheel diameter and contact-point spacing. Log five 500 mm runs without changing code between trials.

## Check and adjust

Your notes distinguish repeatable bias from run-to-run scatter. If error changes direction, inspect loose parts and grip before geometry.
