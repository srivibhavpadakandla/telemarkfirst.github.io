# Lesson F6.2: Parameters and Return Values

A parameter receives a value at a function call, and `return` passes a result back to the caller. Use a distance parameter to vary a route and a returned Boolean to report whether a sensor cue occurred. This keeps the result with the call instead of changing an unrelated global variable.

## Worked example

~~~python
def approach_line(max_mm):
    robot.straight(max_mm)
    return color_sensor.reflection() < 35

line_found = approach_line(250)
print("Line found:", line_found)
~~~

## Simulator practice

Change max_mm to 350 and compare line_found. Explain why return does not move the robot.
