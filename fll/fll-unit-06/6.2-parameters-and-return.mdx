# Lesson F6.2: Parameters and Return Values

The function in the previous lesson always ran the same route. A parameter lets a call choose its distance, while `return` gives the caller a result. This lesson uses a distance parameter to move and a Boolean return value to report whether the color sensor sees the line at the end.

## Worked example

`approach_line(250)` passes 250 into `max_mm`. After driving, the function compares reflection with 35 and returns `True` or `False`. `line_found` stores that result; `return` itself does not move the robot.

~~~python
def approach_line(max_mm):
    robot.straight(max_mm)
    return color_sensor.reflection() < 35

line_found = approach_line(250)
print("Line found:", line_found)
~~~

## Simulator practice

The simulator's line gives the return value something to test. A run with 250 mm and another with 350 mm may end at different sensor positions, so comparing `line_found` can show whether the endpoint affects the result.

## On the robot

On the physical mat, a measured approach distance should leave room for the robot to stop safely. Three starts with that value can show whether the returned Boolean agrees with where the color sensor ends up.

## Check and adjust

The call's number should reach `max_mm`, and the returned Boolean should reach `line_found`. If every result is `False`, an endpoint reflection print may show whether the sensor ever reached the line.
