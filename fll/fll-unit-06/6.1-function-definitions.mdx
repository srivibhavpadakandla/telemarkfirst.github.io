# Lesson F6.1: Define and Call Functions

A function groups an action in an indented body, but that body runs only when the program calls it. Name a routine for its result, such as `approach_line`, and keep DriveBase setup outside the function so each call uses the same calibrated robot.

## Worked example

~~~python
def leave_home():
    robot.straight(250)
    robot.turn(90)

leave_home()
print("Launch route finished")
~~~

## Simulator practice

Call leave_home twice with a reset between runs. Remove the call once and confirm no movement occurs.
