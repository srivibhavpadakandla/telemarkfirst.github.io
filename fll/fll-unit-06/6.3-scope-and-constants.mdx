# Lesson F6.3: Scope and Calibration Constants

A local variable exists inside its function, while a named calibration constant can be shared across route functions. Keep measured dimensions near the top of the program and use distinct names for field distances and sensor readings. In Python, uppercase names signal values the team intends to keep fixed during a run.

## Worked example

~~~python
LINE_THRESHOLD = 35

def is_on_line():
    light_percent = color_sensor.reflection()
    return light_percent < LINE_THRESHOLD

print(is_on_line())
~~~
