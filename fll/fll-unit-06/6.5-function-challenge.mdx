# Lesson F6.5: Reusable Route Challenge

This challenge uses one route function more than once. The simulator checks for a function definition, at least two calls to a route function, and movement without a collision. A return toward home gives those calls a route to describe, even though the check focuses on reuse and safe motion.

## Worked example

`drive_and_turn()` takes a distance and a turn angle. Four calls request the sides and corners of a rectangle. If those distances and turns match the field, the path should finish near its starting point.

~~~python
def drive_and_turn(distance_mm, turn_deg):
    robot.straight(distance_mm)
    robot.turn(turn_deg)

drive_and_turn(300, 90)
drive_and_turn(50, 90)
drive_and_turn(300, 90)
drive_and_turn(50, 90)
~~~

## Simulator practice

The example gives the simulator a route that calls the same function four times. Changing one width in its call values may move the final position, which you can compare with a prediction from the route shape.

## On the robot

Three physical runs from the same launch mark can show how closely the rectangle closes. Recording each final position may help separate a repeated distance error from a turn that varies.

## Check and adjust

The simulator should record a function definition, repeated calls, and motion without collision. On the mat, a rectangle that does not close may need its sides and turns measured separately.
