# Lesson F6.4: Represent a Route with a List

Several measured moves can be stored in a list instead of written as separate calls. Each pair in this lesson gives a straight distance in millimeters and then a turn in degrees. A loop can run the pairs in order, making the route table visible in one place.

## Worked example

The first pair requests a 300 mm drive and 90 degree turn. The second uses a negative turn, and the third skips turning because its angle is zero. Changing one pair should change one part of the route without rewriting the loop.

~~~python
route = [(300, 90), (50, -90), (150, 0)]
for distance_mm, turn_deg in route:
    robot.straight(distance_mm)
    if turn_deg != 0:
        robot.turn(turn_deg)
~~~

## Simulator practice

The starter already uses a function for one drive. Replacing its route with the list above gives the simulator three drive segments to show. A change to the second pair should affect the middle segment and may change the final pose.

## On the robot

A notebook table with distance and turn columns can help another teammate check the route. Physical measurements after each segment may show where the path first differs from that table.

## Check and adjust

Each route pair should cause one straight segment and, unless its angle is zero, one turn. If a segment looks wrong, check the pair's order and units before changing the loop.
