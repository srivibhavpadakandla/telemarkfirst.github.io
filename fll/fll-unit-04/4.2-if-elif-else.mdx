# Lesson F4.2: Choose One Branch

An `if`/`elif`/`else` chain chooses one action from several conditions in order. Put urgent cases first so a close obstacle stops the robot before a lower priority color cue can trigger another action, and reserve `else` for the normal case. Arrange known field states to test every branch.

## Worked example

~~~python
range_mm = distance_sensor.distance()
light = color_sensor.reflection()
if range_mm < 150:
    robot.stop()
    print("stop")
elif light < 35:
    robot.turn(90)
    print("line")
else:
    robot.straight(100)
    print("clear")
~~~

## Simulator practice

Keep the field fixed. Change the numeric thresholds to trigger each branch in turn, and verify only one action runs per test.
