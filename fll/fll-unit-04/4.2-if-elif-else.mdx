# Lesson F4.2: Choose One Branch

One sensor comparison can choose between two outcomes. With `if`, `elif`, and `else`, the robot can choose one of several actions in priority order. Here a close obstacle should stop the route before a dark-line reading can trigger a turn; a clear field allows a short drive.

## Worked example

Python checks `range_mm < 150` first. It checks the line reading only if that first condition is false, and it runs the `else` block only if neither condition is true. The printed word can show which branch ran in a test.

~~~python
range_mm = distance_sensor.distance()
light = color_sensor.reflection()
if range_mm < 150:
    robot.stop()
    print("stop")
elif light < 35:
    robot.turn(90)
    print("line")
else:
    robot.straight(100)
    print("clear")
~~~

## Simulator practice

The simulator field can stay fixed while you change a threshold to make each branch run in turn. The output should show `stop`, `line`, or `clear`, with only one of those words per run. Restoring the chosen thresholds afterward lets you test the intended priority.

## On the robot

The first physical tests should keep the wheels lifted while you compare printed readings and branches. Low-speed mat trials can then show whether the chosen thresholds match the real obstacle and line.

## Check and adjust

A useful test log should include one case for each printed result. If more than one action appears in a run, check the indentation and whether the actions belong to a single `if`/`elif`/`else` chain.
