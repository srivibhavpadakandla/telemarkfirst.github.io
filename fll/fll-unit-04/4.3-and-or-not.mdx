# Lesson F4.3: Combine Conditions

Use `and` when both conditions are required, `or` when either is enough, and `not` when the opposite of a Boolean is needed. A mission action might require a nearby object and a clear tool position. Name those intermediate results so the full condition remains readable. Parentheses help when `and` and `or` appear together.

## Worked example

~~~python
near_object = distance_sensor.distance() < 160
on_dark_line = color_sensor.reflection() < 35
safe_to_pick = near_object and not on_dark_line
if safe_to_pick:
    attachment.run_angle(180, 60)
else:
    print("Pickup condition failed")
~~~
