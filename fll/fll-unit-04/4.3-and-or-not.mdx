# Lesson F4.3: Combine Conditions

We can now combine sensor comparisons into one decision. `and` requires both conditions, `or` accepts either, and `not` reverses a Boolean. This lesson uses a nearby object and a light surface as the two requirements for moving an attachment. Naming each result can make the combined condition easier to read.

## Worked example

`near_object` and `on_dark_line` are calculated separately. `safe_to_pick` is true only when the object is near and the sensor is away from the dark line. If either part fails, the example prints a message instead of moving the tool.

~~~python
near_object = distance_sensor.distance() < 160
on_dark_line = color_sensor.reflection() < 35
safe_to_pick = near_object and not on_dark_line
if safe_to_pick:
    attachment.run_angle(180, 60)
else:
    print("Pickup condition failed")
~~~

## Simulator practice

There are four possible pairs of values for two Booleans. Testing each pair before reading the field sensors can show that only `True` for `near_object` and `False` for `on_dark_line` moves the tool.

## On the robot

Before powering the physical tool, its path should be clear even when `safe_to_pick` is true. The Boolean checks sensor values; they cannot detect every object that might block the attachment.

## Check and adjust

The tool should move only for the intended combination. If it moves at another time, the printed intermediate Booleans may show which comparison gave an unexpected result.
