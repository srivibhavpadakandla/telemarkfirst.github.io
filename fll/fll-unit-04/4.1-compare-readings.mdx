# Lesson F4.1: Compare Sensor Readings

After reading a sensor, we can compare its value with a threshold. The comparison gives `True` or `False`, which a program can use to choose an action. This lesson tests a range threshold in millimeters, including the exact boundary where the result changes.

## Worked example

`too_close` is true only when `range_mm` is less than 150. A reading of exactly 150 gives `False` because the operator is `<`. Printing the reading and Boolean before the `if` makes that boundary visible.

~~~python
range_mm = distance_sensor.distance()
too_close = range_mm < 150
print("Range mm:", range_mm)
print("Too close:", too_close)
if too_close:
    robot.stop()
~~~

## Simulator practice

Values of 149, 150, and 151 mm should give `True`, `False`, and `False` for this comparison. Trying those values in a short Python list can show the boundary before you compare the simulator's fixed obstacle reading.

## On the robot

On the physical robot, the measured gap at the moment the condition changes may differ from the sensor reading. The sensor's position on the chassis should be included when you compare that gap with 150 mm.

## Check and adjust

The printed Boolean should change at the boundary you chose. If it changes at an unexpected physical gap, check the units and sensor mounting position before changing the number.
