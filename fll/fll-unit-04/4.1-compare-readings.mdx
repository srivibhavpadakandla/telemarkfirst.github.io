# Lesson F4.1: Compare Sensor Readings

A comparison returns `True` or `False` when a sensor value meets a rule. Compare values in the same unit: a distance can be below a gap in millimeters, while a reflection can be above a threshold in percent. Print the Boolean result before using the condition to change motor motion.

## Worked example

~~~python
range_mm = distance_sensor.distance()
too_close = range_mm < 150
print("Range mm:", range_mm)
print("Too close:", too_close)
if too_close:
    robot.stop()
~~~

## Simulator practice

Test the comparison with a Python list containing 149, 150, and 151 mm. Then print the reading from the fixed field and compare it with the chosen threshold.
