# Lesson F4.5: Decision Challenge

This challenge combines a distance reading, a line reading, and a time limit in one approach. The aim is a route that stops before a collision and prints which condition ended it. The simulator checks for an ultrasonic reading, an `if` decision, and a stop without collision.

## Worked example

`reason` starts as `"timeout"`. Each sensor can replace that word and break out of the loop; otherwise the four-second limit ends the loop. `robot.stop()` sits after the loop, so every exit reaches the stop call.

~~~python
watch = StopWatch()
reason = "timeout"
robot.drive(100, 0)
while watch.time() < 4000:
    if distance_sensor.distance() < 150:
        reason = "obstacle"
        break
    if color_sensor.reflection() < 35:
        reason = "line"
        break
    wait(10)
robot.stop()
print(reason)
~~~

## Simulator practice

With the field fixed, changing thresholds and the timeout can make `obstacle`, `line`, and `timeout` appear in separate runs. Each run should stop. The threshold values used for the final route should come from the readings observed on the practice field.

## On the robot

Low-speed mat trials can show whether each printed reason matches the physical stop point. A clear lane is useful for testing the timeout without putting an obstacle in the robot's path.

## Check and adjust

The program should stop for all three reasons. If the no-cue run lasts longer than planned, check that the timer is advancing and that the stop call follows the loop.
