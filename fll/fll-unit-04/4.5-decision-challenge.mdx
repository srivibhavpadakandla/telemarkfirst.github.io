# Lesson F4.5: Decision Challenge

Approach the practice obstacle with a bounded loop, stopping for a valid range reading or taking a different action if the dark line appears first. Give those cues a clear priority and print the reason for stopping. Test obstacle first, line first, and no cue so the timeout path also ends safely.

## Worked example

~~~python
watch = StopWatch()
reason = "timeout"
robot.drive(100, 0)
while watch.time() < 4000:
    if distance_sensor.distance() < 150:
        reason = "obstacle"
        break
    if color_sensor.reflection() < 35:
        reason = "line"
        break
    wait(10)
robot.stop()
print(reason)
~~~

## Simulator practice

Keep the field fixed. Change thresholds and timeout values to exercise each printed reason, then restore calibrated values. Confirm every run stops.
