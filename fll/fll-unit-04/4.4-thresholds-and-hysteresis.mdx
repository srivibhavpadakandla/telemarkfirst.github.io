# Lesson F4.4: Avoid Threshold Chatter

A reflected-light reading may hover around one threshold while the robot is near the edge of a line. Two thresholds can keep the state from switching on every small change. In this lesson, a reading below 30% enters the dark state, and a reading above 40% leaves it. The previous state must be kept between readings for that gap to work.

## Worked example

This fragment shows one update to `on_line`. A light reading between 30% and 40% leaves the state as it was. To test several readings, the same `on_line` variable needs to be reused rather than reset to `False` before each reading.

~~~python
light = color_sensor.reflection()
on_line = False
if not on_line and light < 30:
    on_line = True
elif on_line and light > 40:
    on_line = False
print("On line:", on_line)
~~~

## Simulator practice

The sequence 50, 29, 35, and 41 percent should produce states of light, dark, dark, and light when the state persists. A loop over those values can test the rule before you compare it with readings from the simulator line.

## On the robot

Five readings on each physical surface may show how much they vary. A gap between the two thresholds should be wider than ordinary variation near the line edge, while still separating the surfaces you need to detect.

## Check and adjust

The state should hold steady for readings between 30% and 40%. If it changes repeatedly at an edge on the physical mat, the measured variation may call for a wider gap or a steadier sensor height.
