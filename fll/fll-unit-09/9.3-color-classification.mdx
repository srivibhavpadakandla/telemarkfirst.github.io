# Lesson F9.3: Classify a Field Color

`ColorSensor.color()` returns a Pybricks Color value that can identify a large, clearly colored target. Test labels on the actual mission model because lighting, distance, and texture affect readings. For a dark line whose color label varies, reflected light may provide a steadier edge cue.

## Worked example

~~~python
from pybricks.parameters import Color

seen = color_sensor.color()
print("Color:", seen)
if seen == Color.GREEN:
    print("Delivery zone")
~~~

## Simulator practice

Print the color at the fixed start. Then use short drive and turn commands to visit a colored zone and print again. Record the route and both labels.

## On the robot

Collect labels for each surface at the intended mounting height. Move the robot a few millimeters and test again.

## Check and adjust

You can state which surfaces classify consistently and which need a numeric reflection test. If labels vary with pose, use reflection or a larger target.

Reference: [Pybricks ColorSensor reference](https://docs.pybricks.com/en/stable/pupdevices/colorsensor.html).
