# Lesson F9.3: Classify a Field Color

Reflected light gives a number, while `ColorSensor.color()` gives a Pybricks Color label. A large colored target may be easier to identify by label. This lesson compares labels at two field positions, then asks whether the same label is dependable on the actual mission model.

## Worked example

The program prints the current label and gives a message only when it is green. It does not move the robot to a colored area; that route is part of the practice.

~~~python
from pybricks.parameters import Color

seen = color_sensor.color()
print("Color:", seen)
if seen == Color.GREEN:
    print("Delivery zone")
~~~

## Simulator practice

Start with the worked example to print a label at the fixed start, then add a short route to the colored zone and print again. Comparing both readings can show whether the sensor reached the intended surface.

## On the robot

On the real robot, labels should be collected at the intended sensor height. Moving a few millimeters and repeating the reading can reveal a sensitive edge or uneven target.

## Check and adjust

Record which labels remain consistent across nearby positions. If a label changes easily, reflected light or a larger target may be more useful for that mission.

Reference: [Pybricks ColorSensor reference](https://docs.pybricks.com/en/stable/pupdevices/colorsensor.html).
