# Lesson F9.1: Calibrate Reflected Light

Now that the robot can cross the practice line, we can measure how its sensor sees the mat and the dark surface. Several readings at the intended mounting height should show whether the ranges are separate enough for a threshold. A midpoint may be a useful first value, although line edges and lighting can change the readings.

## Worked example

The two lists come from positions before and after a drive. The candidate threshold is halfway between the lowest light sample and the highest dark sample, so it is useful only if the two ranges have a gap.

~~~python
light_samples = [color_sensor.reflection() for _ in range(5)]
robot.straight(750)
dark_samples = [color_sensor.reflection() for _ in range(5)]
print("Light:", light_samples, "Dark:", dark_samples)
threshold = (min(light_samples) + max(dark_samples)) / 2
print("Candidate:", threshold)
~~~

## Simulator practice

Use the worked example to collect five readings at the fixed start and five more after the drive. The second set should come from the line; the drive distance may need adjusting if the sensor stops elsewhere.

## On the robot

Collect five values on each surface with the real sensor mounted as it will be used. If the ranges do not overlap, a threshold between the highest dark and lowest light reading can be tested at the line edge.

## Check and adjust

The recorded ranges should show why a threshold was chosen. If they overlap, a mounting change or another set of readings may help before the stop code is used.
