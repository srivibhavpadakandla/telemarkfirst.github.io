# Lesson F9.4: Follow an Edge Briefly

A line follower can steer toward an edge by comparing current reflection with a target value. The difference, called an error, changes the turn rate each time the loop runs. Here we will test the direction of that correction at low speed for a short interval. The simulator's short line supports a steering demonstration, not a long route.

## Worked example

The sign of `error * 0.5` determines which way the robot turns. A single sensor can lose track of which side of the line it is on after it leaves the edge entirely.

~~~python
target = 35
watch = StopWatch()
while watch.time() < 300:
    error = color_sensor.reflection() - target
    robot.drive(40, error * 0.5)
    wait(20)
robot.stop()
~~~

## Simulator practice

Try the worked example's 300 ms steering loop, then reverse the correction sign and compare the headings. The result can show which direction moves the sensor toward the edge.

## On the robot

A wide practice line and clear space should be used for the first physical test. Record whether the sensor stays near the intended edge for the brief run.

## Check and adjust

The timer should stop the drive after the short test. If the correction steers away from the chosen edge, its sign may need reversing before a longer attempt.
