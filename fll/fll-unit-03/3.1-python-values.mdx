# Lesson F3.1: Numbers, Booleans, and Text

The route now has numbers we may need to change. Python can store those numbers alongside Boolean values such as `True` and text such as `"launch"`. This lesson compares those value types so we can choose a distance for a drive and print a useful label with it. A number inside quotes is text and cannot be used directly in arithmetic.

## Worked example

`distance_mm` and `turn_deg` hold numbers, `at_home` holds a Boolean, and `label` holds text. The print line shows all four values, while `robot.straight()` uses the numeric distance. Changing the label should affect the output without changing the drive.

~~~python
distance_mm = 300
turn_deg = 90
at_home = True
label = "launch"
print(label, distance_mm, "mm", at_home)
robot.straight(distance_mm)
~~~

## Simulator practice

The starter drives using `distance_mm`. A second run with 450 instead of 300 should end farther from the start. Adding the print line from the example can help you check that the value sent to the drive matches the one you intended.

## On the robot

Before a physical drive, printing the planned distance with `mm` beside it can help catch a value in the wrong unit. A Boolean such as `at_home` may also be useful when you later add a condition to a route.

## Check and adjust

The printed values should make it possible to identify which entries are numbers, text, and Booleans. If a distance calculation fails, a quoted number such as `"300"` may be the cause.
