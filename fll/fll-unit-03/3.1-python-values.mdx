# Lesson F3.1: Numbers, Booleans, and Text

Python uses whole numbers, decimal numbers, Booleans, and strings for different jobs in robot code. Keep distance and speed as numbers, use `True` or `False` for a condition, and use text for a console label. A number in quotes cannot be used as a number in a calculation, so print values with their units when checking a route.

## Worked example

~~~python
distance_mm = 300
turn_deg = 90
at_home = True
label = "launch"
print(label, distance_mm, "mm", at_home)
robot.straight(distance_mm)
~~~
