# Lesson F3.3: Arithmetic for Motion

Calculate route commands from measured distances instead of scattering unrelated constants through a program. Add or subtract clearances in millimeters, and use a negative straight distance when the robot needs to reverse. Print intermediate values before sending a calculated result to a motor command.

## Worked example

~~~python
field_gap_mm = 420
tool_clearance_mm = 55
approach_mm = field_gap_mm - tool_clearance_mm
robot.straight(approach_mm)
print("Approach:", approach_mm, "mm")
~~~

## Simulator practice

Change the clearance from 55 to 70 mm and predict the new stopping position.

## On the robot

Measure the gap from launch to a safe tool position. Record the clearance you chose and why.

## Check and adjust

You can calculate the approach distance without trial-and-error changes to several commands. If the approach stops too close, remeasure tool clearance.
