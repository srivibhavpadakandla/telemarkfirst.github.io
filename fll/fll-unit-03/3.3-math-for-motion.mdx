# Lesson F3.3: Arithmetic for Motion

A robot tool may need to stop before it reaches a model. We can calculate that approach distance from a measured gap and a tool clearance. This lesson uses one subtraction in millimeters so the drive command can follow a measurement rather than a guessed constant.

## Worked example

The field gap is 420 mm and the chosen tool clearance is 55 mm. Subtracting gives an approach command of 365 mm. Printing `approach_mm` makes the number visible when you compare the result with the field.

~~~python
field_gap_mm = 420
tool_clearance_mm = 55
approach_mm = field_gap_mm - tool_clearance_mm
robot.straight(approach_mm)
print("Approach:", approach_mm, "mm")
~~~

## Simulator practice

Increasing the clearance to 70 mm should shorten the approach to 350 mm. Predicting that value before a second simulator run can help you check whether the calculation and final pose agree.

## On the robot

The real field gap and tool reach should be measured from fixed reference points. A clearance chosen from those measurements may leave room for the attachment to act without the chassis touching the model.

## Check and adjust

The printed approach distance should equal the measured gap minus the chosen clearance. If the robot stops too close to the model, check where both measurements were taken before changing the subtraction.
