# Lesson F3.2: Variables and Units

A variable gives a measured value a name, and a unit in that name can prevent a distance or angle from being used incorrectly. DriveBase distances use millimeters, color reflection uses percent, and motor angles use degrees. Convert at a clear boundary so another teammate can find the value to adjust after measuring the robot.

## Worked example

~~~python
TARGET_CM = 30
target_mm = TARGET_CM * 10
speed_mm_s = 150
print("Target:", target_mm, "mm")
robot.settings(speed_mm_s, 300, 90, 180)  # mm/s, mm/s², deg/s, deg/s²
robot.straight(target_mm)
~~~

## Simulator practice

Change TARGET_CM to 40. Check that the robot moves 400 mm, not 40 mm.
