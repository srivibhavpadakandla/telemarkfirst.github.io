# Lesson F14.5: Full Match Capstone

The final project brings the route, robot measurements, sensor choices, and match plan together. The intended program should attempt the practice target and delivery objectives and return home. Repeated runs and a failed-cue test can show how well the plan works beyond one successful attempt.

## Worked example

The sample function traces one generic-field route and prints its time. It provides a starting shape for the project; tested mission functions, sensor checks, and the team's own measurements still need to be added.

~~~python
def run_match():
    watch = StopWatch()
    print("Start light:", color_sensor.reflection())
    robot.straight(1380)
    attachment.run_angle(160, 90)
    robot.turn(180)
    robot.straight(430)
    robot.turn(90)
    robot.straight(180)
    robot.straight(480)
    robot.turn(90)
    robot.straight(830)
    attachment.run_angle(160, -90)
    robot.turn(180)
    robot.straight(1780)
    robot.turn(-90)
    robot.straight(660)
    robot.stop()
    print("Run ms:", watch.time())

run_match()
~~~

## Simulator practice

Replace the sample route with tested functions, then run under the 150 second clock. Record the target, delivery, and home results for every attempt.

## On the robot

Five complete physical trials can provide a success count, longest time, and a useful example of failure and recovery. Keep the last reliable source file with the robot's port map, geometry, thresholds, and launch marks.

## Check and adjust

The final record should let a teammate reproduce the launch and explain the route's results. Include every trial, even when an objective fails, and use current FIRST materials for any real season score.
