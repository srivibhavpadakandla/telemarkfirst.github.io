# Lesson F14.5: Full Match Capstone

Complete the practice target and delivery objectives, return home, and document repeated runs. Submit the Python source, port map, wheel geometry, sensor thresholds, launch marks, and at least five trial results. Include a failed cue test with its safe response, and use current FIRST materials for any real season scoring claim.

## Worked example

~~~python
def run_match():
    watch = StopWatch()
    print("Start light:", color_sensor.reflection())
    robot.straight(1380)
    attachment.run_angle(160, 90)
    robot.turn(180)
    robot.straight(430)
    robot.turn(90)
    robot.straight(180)
    robot.straight(480)
    robot.turn(90)
    robot.straight(830)
    attachment.run_angle(160, -90)
    robot.turn(180)
    robot.straight(1780)
    robot.turn(-90)
    robot.straight(660)
    robot.stop()
    print("Run ms:", watch.time())

run_match()
~~~
