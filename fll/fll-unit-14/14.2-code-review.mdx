# Lesson F14.2: Review Units and Stops

Before a full run, check the unit at every movement call and confirm that each continuous drive has a stop path. DriveBase distances use millimeters, angles use degrees, motor speeds use degrees per second, and waits use milliseconds. Test missing cues and invalid range values, then remove unused code that could confuse a match day edit.

## Worked example

~~~python
def approach_safely(limit_ms):
    watch = StopWatch()
    robot.drive(100, 0)
    while distance_sensor.distance() > 150 and watch.time() < limit_ms:
        wait(10)
    robot.stop()
    return watch.time() < limit_ms

print("Cue found:", approach_safely(3000))
~~~

## Simulator practice

Run once with a 1 ms timeout and once with the normal 3000 ms timeout. Inspect whether both paths stop on the fixed field.
