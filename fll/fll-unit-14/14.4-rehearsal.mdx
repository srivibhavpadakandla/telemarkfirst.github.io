# Lesson F14.4: Rehearse a Match

A match rehearsal combines code with the people and handling around it. The team can practice program choice, launch alignment, attachments, and returns under the full 150 second clock. The current FIRST rulebook should guide real scoring and handling decisions.

## Worked example

The loop prints two launch names and timestamps, then runs a simple action for each. It illustrates order and timing but does not model the physical reset or attachment handoff between launches.

~~~python
watch = StopWatch()
for mission_name in ["line", "target"]:
    print("Launch:", mission_name, "at ms:", watch.time())
    if mission_name == "line":
        robot.straight(250)
    else:
        attachment.run_angle(160, 60)
    robot.stop()
print("Rehearsal ms:", watch.time())
~~~

## Simulator practice

Use the worked loop as a timing outline, then add the planned route for each launch. The simulator clock can show the code time, while a full physical rehearsal also needs human handling time.

## On the robot

The actual match team should time a complete physical rehearsal with the intended attachments. Record handling delays and any recovery along with the drive time.

## Check and adjust

The plan should be clear enough to follow at the field without reading the source. If the rehearsal exceeds the estimate, include its handling time in the budget and keep the last reliable program available.
