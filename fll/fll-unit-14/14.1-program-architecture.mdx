# Lesson F14.1: Organize the Program

Arrange imports and device setup first, measured constants next, mission functions after them, and the launch choice last. Keep port assignments and wheel dimensions easy for teammates to find, and pass measured parameters when launches use different values. Limit shared program state to values with a clear purpose.

## Worked example

~~~python
WHEEL_DIAMETER_MM = 56
AXLE_TRACK_MM = 112
LINE_THRESHOLD = 35

def line_mission():
    robot.straight(250)
    return color_sensor.reflection() < LINE_THRESHOLD

result = line_mission()
print("Line mission:", result)
~~~

## On the robot

Print the program and ask a teammate to locate ports, geometry, and the main launch function.

## Check and adjust

A new teammate can identify what to measure and where to update it. If a value is hard to find, move it into named configuration.
