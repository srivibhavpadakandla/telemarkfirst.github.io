# Lesson F1.2: Distance and Wait Until

An UltrasonicSensor reports the distance to a nearby object in millimeters and returns 2000 when it has no valid reading. Poll it while the drive base moves, but include a timeout so a missing object cannot leave the robot driving indefinitely. Stop the drive base when either the distance condition or the timeout ends the loop.

## Worked example

~~~python
watch = StopWatch()
robot.drive(100, 0)
while distance_sensor.distance() > 150 and watch.time() < 3000:
    wait(10)
robot.stop()
print("Range:", distance_sensor.distance())
~~~

## Simulator practice

Run toward the fixed obstacle and record whether range or the three-second timeout ends the drive. Change the range threshold, rerun, and compare the stop point.

## On the robot

Measure the stop gap with a ruler. Repeat with a broad target and with an angled target to see how shape changes range readings.

## Check and adjust

Range should stop the drive when a target is present, and the timeout should stop it when the target is absent. If either run continues, check where `robot.stop()` executes.

Reference: [Pybricks UltrasonicSensor reference](https://docs.pybricks.com/en/stable/pupdevices/ultrasonicsensor.html).
