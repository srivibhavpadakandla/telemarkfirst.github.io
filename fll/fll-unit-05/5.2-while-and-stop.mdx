# Lesson F5.2: Repeat Until a Cue

In F1.1 we used a line reading to stop a drive. A `while` loop makes that behavior possible because it checks the condition again after every pass. This lesson focuses on where the repeated reading happens and where the stop call belongs. If the line is missed, the loop will need a timeout, which we add later in this unit.

## Worked example

`robot.drive(100, 0)` continues until another command stops it. Each pass through the loop waits 10 ms, then `color_sensor.reflection()` is checked again. When a reading is 35% or lower, Python leaves the loop and calls `robot.stop()`.

~~~python
robot.drive(100, 0)
while color_sensor.reflection() > 35:
    wait(10)
robot.stop()
~~~

## Simulator practice

Replace the starter's fixed-distance loop with the worked example's sensor loop. The simulator line should lower reflection enough to end it, and the field view can show where the sensor is at the stop. A real mat may need a different threshold.

## On the robot

The first physical trial should be slow and start near the line. Watching where the sensor and wheels are when the robot stops can show whether the threshold and speed suit the available space.

## Check and adjust

The condition should be checked after each 10 ms wait, and `robot.stop()` should run after the loop ends. If the robot never detects the line, a timeout can bound the drive in the next lesson.
