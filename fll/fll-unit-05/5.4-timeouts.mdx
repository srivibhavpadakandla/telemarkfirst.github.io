# Lesson F5.4: Add a Timeout

A timeout gives a sensor wait a definite upper limit when the expected cue never appears. Start the watch immediately before continuous motion, stop the drive base after either exit condition, and print whether the cue or timer ended the loop. That result helps distinguish a missing target from a poorly chosen threshold.

## Worked example

~~~python
watch = StopWatch()
robot.drive(120, 0)
while color_sensor.reflection() > 35 and watch.time() < 3000:
    wait(10)
robot.stop()
if watch.time() >= 3000:
    print("Timed out")
else:
    print("Line found")
~~~

## Simulator practice

Run with the fixed line. Then set the line threshold below zero to force the timeout case. Restore the measured threshold after the test.

## On the robot

Test on an unobstructed practice surface first. Keep one hand ready at the hub stop button during the first timed run.

## Check and adjust

Both tests should stop, and the printed exit reason should match the field condition. If the timeout is ignored, start the watch before the drive.
