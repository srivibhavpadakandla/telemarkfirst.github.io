# Lesson F5.4: Add a Timeout

A line stop needs a backup when the sensor never sees the line. A stopwatch can bound the wait so the drive ends after three seconds even if reflection stays above the threshold. The printed result should then tell us whether the line or the time limit ended the route.

## Worked example

The `while` condition requires both a light reading above 35% and elapsed time below 3000 ms. `robot.stop()` runs after either condition fails. The final `if` uses the watch to print which exit likely occurred.

~~~python
watch = StopWatch()
robot.drive(120, 0)
while color_sensor.reflection() > 35 and watch.time() < 3000:
    wait(10)
robot.stop()
if watch.time() >= 3000:
    print("Timed out")
else:
    print("Line found")
~~~

## On the robot

The first physical timeout test should use a clear practice surface and a person ready at the hub stop button. A timed stop there can show whether the backup works before the robot is sent toward a field model.

## Check and adjust

Both runs should reach `robot.stop()`, and the printed result should match the condition that ended each run. If the route lasts too long, check that the watch starts before the drive and that the loop compares its time.
