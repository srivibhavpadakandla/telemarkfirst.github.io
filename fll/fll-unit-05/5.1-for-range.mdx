# Lesson F5.1: Repeat a Known Count

Some tests need the same movement more than once. A `for` loop repeats a known number of times, and `range(3)` gives the loop the values 0, 1, and 2. Here we will use it for three short out-and-back moves and print the trial number so each movement can be identified in the output.

## Worked example

The body runs once for each value from `range(3)`. Adding one to `trial` prints 1, 2, and 3, while the two straight commands request an out-and-back move on each repeat.

~~~python
for trial in range(3):
    print("Trial:", trial + 1)
    robot.straight(100)
    robot.straight(-100)
~~~

## Simulator practice

The starter repeats only an outward move. Add the reverse command and trial print from the worked example inside its loop. It should then show three out-and-back movements for `range(3)` and two for `range(2)`.

## On the robot

The first physical test should have the wheels lifted so you can count the repeats. On the floor, a start mark can show whether each out-and-back movement returns to the same place.

## Check and adjust

The number of printed trials should match the number of completed moves. If it does not, check the `range()` value and which lines are indented under `for`.
