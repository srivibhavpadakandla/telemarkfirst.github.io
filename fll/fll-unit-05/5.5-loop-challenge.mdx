# Lesson F5.5: Loop and Timeout Challenge

This challenge combines the loop, sensor readings, and timeout from the unit. The aim is an approach that can stop for a line, an obstacle, or a four-second limit and report the reason. The simulator checks that a loop reads reflected light or time, moves the robot, and calls `robot.stop()` without a collision.

## Worked example

`reason` begins as `"timeout"`. A line or obstacle reading can replace it and break out of the loop. If neither condition is met, the watch ends the loop; the stop call is outside all three exit paths.

~~~python
watch = StopWatch()
reason = "timeout"
robot.drive(100, 0)
while watch.time() < 4000:
    if color_sensor.reflection() < 35:
        reason = "line"
        break
    if distance_sensor.distance() < 150:
        reason = "obstacle"
        break
    wait(10)
robot.stop()
print(reason)
~~~

## Simulator practice

The fixed field can support separate tests by changing a threshold or the time limit. Each test should print the reason expected for that setup and end with the robot stopped. Resetting between runs keeps the starting pose comparable.

## On the robot

Low-speed physical trials may show whether the three stop reasons correspond to different field positions. Marks or photos of those positions can help when choosing the final thresholds.

## Check and adjust

Every loop exit should lead to `robot.stop()`. If a test keeps driving, check for a path that bypasses the stop and for a time condition that never becomes false.
