# Lesson F5.5: Loop and Timeout Challenge

Build one loop that checks for the line or obstacle and stops the approach within four seconds in every case. Print or return the reason for stopping, then record the final position for a line, an obstacle, and a run with neither cue.

## Worked example

~~~python
watch = StopWatch()
reason = "timeout"
robot.drive(100, 0)
while watch.time() < 4000:
    if color_sensor.reflection() < 35:
        reason = "line"
        break
    if distance_sensor.distance() < 150:
        reason = "obstacle"
        break
    wait(10)
robot.stop()
print(reason)
~~~

## Simulator practice

Use different threshold values and a short timeout to exercise line, obstacle, and timeout exits on the fixed field. Reset the program between runs.
