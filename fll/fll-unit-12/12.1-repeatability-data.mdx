# Lesson F12.1: Record Repeatability

Run the same code several times and record final position, heading, elapsed time, and mission result. The mean can reveal a consistent bias, while the spread shows how much results vary between runs. Include failures, and keep simulator calibration profiles separate from physical trials because they represent different conditions.

## Worked example

~~~python
times_ms = [3200, 3350, 3280]
mean_ms = sum(times_ms) / len(times_ms)
spread_ms = max(times_ms) - min(times_ms)
print("Mean ms:", mean_ms)
print("Spread ms:", spread_ms)
~~~

## Simulator practice

Run a fixed route once, then compare the automatic three-profile table. Record position, home status, and error for each profile.
