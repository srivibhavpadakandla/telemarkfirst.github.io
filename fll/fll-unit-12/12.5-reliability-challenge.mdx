# Lesson F12.5: Reliability Challenge

This challenge asks whether one route can cross the dark line and return home under the simulator's three calibration profiles. The profile table can reveal how sensitive the route is to changed geometry or motion. A failed profile gives us a place to measure before adjusting the program.

## Worked example

The sample route crosses the line, turns around, and drives the same nominal distance back. The final heading helps check the turn, while the field view shows whether the robot actually reached home.

~~~python
def short_route():
    robot.straight(850)
    robot.turn(180)
    robot.straight(850)

short_route()
print("Final heading:", hub.imu.heading())
~~~

## Simulator practice

Run once and record success, endpoint, heading, and time for each automatic profile. Keeping that baseline makes a later adjustment easier to judge.

## On the robot

Five physical trials with the same program and launch pose can show whether the simulator's sensitivity appears on the real robot. Record both successes and the first failure point.

## Check and adjust

The log should support a claim about the route's repeatability. If one profile fails, locate its first divergence and rerun all three profiles after a measured change.
