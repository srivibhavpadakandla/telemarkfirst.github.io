# Lesson F12.2: Calibrate Wheel Diameter

After recording repeatable straight-drive errors, we can estimate a better wheel diameter. A robot that consistently stops short may need a smaller configured diameter; one that travels too far may need a larger one. The estimate uses the old diameter multiplied by actual distance and divided by requested distance.

## Worked example

The example turns a 480 mm measured drive for a 500 mm request into a new starting value. Axle track stays fixed during this pass so its effect is easier to separate.

~~~python
old_diameter_mm = 56
requested_mm = 500
actual_mm = 480
new_diameter_mm = old_diameter_mm * actual_mm / requested_mm
print("Try wheel diameter mm:", new_diameter_mm)
~~~

## Simulator practice

Try the calculated diameter in code and rerun the 500 mm drive. The automatic profile table can show whether the adjustment improves distance across different calibrations.

## On the robot

At least three measured 500 mm drives can show whether the error is consistent. After trying the estimate on the real robot, another set of measurements should confirm the change.

## Check and adjust

The chosen value should reduce the repeated straight error. If the estimate makes it worse, check which distance was actual and which was requested before adjusting again.
