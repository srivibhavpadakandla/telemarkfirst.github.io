# Lesson F12.4: Recover from a Failed Cue

When a required cue is missing, stop or return before the next tool action. Return a Boolean from the sensor step and check it before moving the attachment. On failure, stop the drive base and follow a short, tested path home that avoids the obstacle involved.

## Worked example

~~~python
def approach_with_timeout():
    watch = StopWatch()
    robot.drive(90, 0)
    while color_sensor.reflection() > 35 and watch.time() < 2500:
        wait(10)
    robot.stop()
    return color_sensor.reflection() <= 35

if approach_with_timeout():
    attachment.run_angle(160, 60)
else:
    print("Skip tool action")
    robot.straight(-150)
~~~

## Simulator practice

Set the line threshold below zero to force the failed-cue branch and verify the attachment does not move. Restore the measured threshold and retest.

## Check and adjust
