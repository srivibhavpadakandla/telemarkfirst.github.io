# Lesson F13.4: Plan a Skip Decision

A match plan can include a choice for limited time or a missed cue. Here a condition checks both time remaining and whether the target is ready. The printed choice represents a decision the team can rehearse before using it with real route functions.

## Worked example

With 38 seconds left but `target_ready` false, the example chooses the short return. Both conditions must be true before it prints the target mission.

~~~python
time_left_s = 38
target_ready = False
if time_left_s >= 30 and target_ready:
    print("Run target mission")
else:
    print("Run short return mission")
~~~

## Simulator practice

Try the worked condition with three time values and both target states. The six printed outcomes can show whether it matches the team's written rule.

## On the robot

The same rule can be rehearsed with a stopwatch and the physical hub slots. Switching programs takes time that should appear in the match budget.

## Check and adjust

A teammate should be able to choose the planned route from the rule without reading source code. If the choice takes too long, the slot labels or handling plan may need simplifying.
