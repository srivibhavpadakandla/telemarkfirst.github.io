# Lesson F13.5: Match Plan Challenge

This challenge brings mission value, timing, order, and fallback into one plan. The team should be able to explain why the first route comes first and how much time remains for the next objective and return. Three complete trials can show whether that plan fits the clock in practice.

## Worked example

The example times two route functions and prints a reading after each. It models movement in one continuous simulator program; physical launches also include handling and may use separate hub slots.

~~~python
watch = StopWatch()

def launch_one():
    robot.straight(1380)
    attachment.run_angle(160, 90)
    attachment.run_angle(160, -90)
    robot.turn(180)
    robot.straight(1380)
    robot.turn(180)

def launch_two():
    robot.straight(850)
    robot.turn(180)
    robot.straight(850)

launch_one()
print("After one ms:", watch.time())
launch_two()
print("Total ms:", watch.time())
~~~

## Simulator practice

Run the sequence under the 150 second clock. Record whether each objective was completed, where the robot ended, and how much time the route used.

## On the robot

Physical rehearsal should include every handoff between launches. Comparing the total with the planned reserve can reveal time missing from the code-only estimate.

## Check and adjust

The final plan should include route order, time estimates, a fallback, and results from three complete trials. A run that uses the reserve may call for a shorter second objective.
