# Lesson F13.5: Match Plan Challenge

Prepare two launches that complete a reliable route first and leave enough time for a second objective and return. Record expected time and score for each launch, then run the full sequence three times in the simulator. Use the written fallback when a mission fails rather than editing code mid-match.

## Worked example

~~~python
watch = StopWatch()

def launch_one():
    robot.straight(1380)
    attachment.run_angle(160, 90)
    attachment.run_angle(160, -90)
    robot.turn(180)
    robot.straight(1380)
    robot.turn(180)

def launch_two():
    robot.straight(850)
    robot.turn(180)
    robot.straight(850)

launch_one()
print("After one ms:", watch.time())
launch_two()
print("Total ms:", watch.time())
~~~

## Simulator practice

Run both launches under the 150 second limit and record objective completion and final home position.

## On the robot

Rehearse all physical handling between launches. Compare the actual duration with the planned reserve.

## Check and adjust

Your plan lists the route order, time estimate, fallback, and three complete trial results. If a run exceeds the reserve, revise the written plan.
