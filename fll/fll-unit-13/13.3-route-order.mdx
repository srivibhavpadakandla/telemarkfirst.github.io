# Lesson F13.3: Order Missions

Mission order affects travel, attachment handling, and the route available after a failure. Start with a reliable launch, then compare two orders using measured time rather than distance alone. Put uncertain actions where a missed cue still leaves a clear return, and label the program and attachment for each launch.

## Worked example

~~~python
mission_order = ["line", "target", "delivery"]
for launch_number, mission in enumerate(mission_order, start=1):
    print("Launch", launch_number, mission)
~~~

## Simulator practice

Run two mission orders on the practice field and record total elapsed time and ending position.

## On the robot

Lay out physical attachments in launch order. Rehearse the handoff between programs with the same people who will run the match.

## Check and adjust

Your written order includes program, attachment, launch mark, expected time, and return plan. If the second route starts in the wrong pose, return home first.
