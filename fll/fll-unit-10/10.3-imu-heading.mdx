# Lesson F10.3: Read and Reset Heading

`PrimeHub.imu.heading()` reports clockwise positive heading in degrees relative to program start or the last reset. Let the robot settle before checking it. If DriveBase uses gyro control, stop the robot and call `robot.reset(angle=0)`. A direct IMU reset during gyro driving raises an error in current Pybricks.

## Worked example

~~~python
robot.stop()
robot.reset(angle=0)
robot.turn(90)
heading_deg = hub.imu.heading()
print("Heading deg:", heading_deg)
~~~
