# Lesson F10.1: Read Ultrasonic Range

`UltrasonicSensor.distance()` reports millimeters and returns 2000 when the current Pybricks API has no valid measurement. A narrow or slanted object may give a poor echo, so treat 2000 as unknown rather than proof of a clear path. Print readings at several measured distances before choosing a mission threshold.

## Worked example

~~~python
range_mm = distance_sensor.distance()
if range_mm == 2000:
    print("No valid range")
else:
    print("Range mm:", range_mm)
~~~

## Simulator practice

Print the initial range, then use a short route toward the fixed obstacle and print again. Adjust the route distance in code to compare readings.
