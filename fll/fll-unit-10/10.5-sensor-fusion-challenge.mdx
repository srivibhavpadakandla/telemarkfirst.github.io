# Lesson F10.5: Sensor Check Challenge

This challenge combines range and heading in a short approach. The robot should stop before contact and report where it is facing. A timeout gives the approach an end even if the target cannot be measured, while actual clearance still needs to be checked on hardware.

## Worked example

The loop stops when the range is below 150 mm, becomes invalid at 2000, or reaches three seconds. The example does not require a valid first reading before motion begins, so that stricter behavior would need an initial range check.

~~~python
watch = StopWatch()
robot.drive(80, 0)
while watch.time() < 3000:
    range_mm = distance_sensor.distance()
    if range_mm < 150 or range_mm == 2000:
        break
    wait(10)
robot.stop()
print("Range mm:", range_mm)
print("Heading deg:", hub.imu.heading())
~~~

## Simulator practice

Try the sample approach on the fixed field, then change its threshold or initial heading. A short timeout can exercise the missing-cue case; every run should end with a stop event.

## On the robot

Reduced speed should be used for the physical approach. Measure the clearance after each stop to see whether the threshold leaves enough room for the real robot.

## Check and adjust

The final log should include both range and heading. If the target is absent, the loop should still exit within three seconds and leave the drive base stopped.
