# Lesson F10.2: Use a Force Sensor

A SPIKE Force Sensor can confirm contact between a tool or bumper and a mission model. The simulator estimates contact from tool angle and proximity, but physical force still needs a hardware reading. `ForceSensor.pressed()` returns a Boolean using a minimum force in newtons. Mount the sensor so the bumper moves before rigid parts hit, and retain a mechanical stop.

## Worked example

~~~python
# Optional Force Sensor on port F:
from pybricks.pupdevices import ForceSensor
bumper = ForceSensor(Port.F)
print("Contact:", bumper.pressed(force=3))
~~~

## Simulator practice

Print contact at the fixed start. Then add a route toward the yellow target and a 60 degree attachment move before a second print. The simulated contact uses approximate position and tool angle.

## On the robot

Install a force sensor on port F, press it by hand, and check both released and pressed results before a slow approach.

## Check and adjust

The simulated contact changes with proximity and tool angle. On hardware, record the actual force at contact. If simulated contact appears at the wrong point, calibrate on hardware.

Reference: [Pybricks ForceSensor reference](https://docs.pybricks.com/en/stable/pupdevices/forcesensor.html).
