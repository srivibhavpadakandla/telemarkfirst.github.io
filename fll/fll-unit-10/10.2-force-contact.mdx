# Lesson F10.2: Use a Force Sensor

A Force Sensor can report whether a bumper or tool has pressed against an object. In the simulator, contact is estimated from position and tool angle; on a robot, `ForceSensor.pressed()` tests a minimum force in newtons. This lesson compares the simulated contact cue with the hardware setup needed to measure real contact.

## Worked example

Port F is only an example assignment. The force threshold and mounting should match the physical bumper, which needs room to move before rigid parts meet the model.

~~~python
# Optional Force Sensor on port F:
from pybricks.pupdevices import ForceSensor
bumper = ForceSensor(Port.F)
print("Contact:", bumper.pressed(force=3))
~~~

## Simulator practice

Use the worked example's force reading at the start, then add a route toward the yellow target and a 60 degree tool move before reading again. A changed value would indicate simulated contact under this approximate model.

## On the robot

With a real sensor on the configured port, hand presses should show both released and pressed results before a slow approach is attempted.

## Check and adjust

Record the actual force and tool position when contact occurs on hardware. The simulator's contact estimate can suggest a route, but the real bumper determines the usable threshold.

Reference: [Pybricks ForceSensor reference](https://docs.pybricks.com/en/stable/pupdevices/forcesensor.html).
