# FLL and Pybricks References

Sources checked November 5, 2026. Check the current season materials again before a competition.

## FIRST rules

- [FIRST LEGO League overview](https://www.firstinspires.org/programs/fll/) describes the Challenge program and the 150-second Robot Game.
- [BIOGLOW season materials](https://www.firstinspires.org/resources/library/fll/season-materials) provides the current Robot Game Rulebook, challenge updates, field setup, and scoresheets. These materials control actual scoring and handling.
- [FIRST K-8 program update](https://www.firstinspires.org/programs/k-8) explains the transition after the 2026-27 season.

## Pybricks setup and API

- [Pybricks installation guide](https://pybricks.com/learn/getting-started/install-pybricks/) explains firmware installation and restoration of LEGO firmware.
- [Pybricks Code guide](https://pybricks.com/learn/getting-started/pybricks-environment/) explains the editor, hub connection, and program slots.
- [DriveBase reference](https://docs.pybricks.com/en/stable/robotics.html) defines millimeter distances, turn degrees, straight(), turn(), arc(), drive(), settings, and gyro use.
- [Motor reference](https://docs.pybricks.com/en/stable/pupdevices/motor.html) defines motor direction, angles, target positions, and stopping behavior.
- [ColorSensor reference](https://docs.pybricks.com/en/stable/pupdevices/colorsensor.html) defines color labels and reflected-light percentage.
- [UltrasonicSensor reference](https://docs.pybricks.com/en/stable/pupdevices/ultrasonicsensor.html) defines distance in millimeters and the 2000 mm invalid-reading value.
- [ForceSensor reference](https://docs.pybricks.com/en/stable/pupdevices/forcesensor.html) defines force in newtons and the pressed threshold.
- [PrimeHub reference](https://docs.pybricks.com/en/stable/hubs/primehub.html) defines IMU heading and reset behavior.
- [Timing tools reference](https://docs.pybricks.com/en/stable/tools/) defines wait() in milliseconds and StopWatch.

Pybricks stable examples use plain synchronous calls for the lessons here. The API reference also marks methods that can be awaited in asynchronous programs. This course introduces no asynchronous runtime in the simulator.

## Course scope

Telemark's practice field is generic. Its BIOGLOW view is a schematic map and does not reproduce official mission hardware, scoring, or every physical effect. Use the current FIRST Robot Game Rulebook to check rules and scores, and test competition programs on your own robot.
