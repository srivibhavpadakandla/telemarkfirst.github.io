# Lesson F7.4: Gearing, Load, and Stalls

Gears change output angle and torque, and Pybricks can describe them with a `gears` list when constructing a Motor. The simulator treats a tool as a simple angle driven mechanism, so measure physical travel separately. Use low force for deliberate homing with `run_until_stalled()` and a duty limit. An ordinary tool move should not rely on a stall against a fragile attachment.

## Worked example

~~~python
# On real hardware, after checking the mechanism:
# attachment = Motor(Port.E, gears=[12, 36])
# attachment.run_until_stalled(-100, duty_limit=30)
# attachment.reset_angle(0)
attachment.run_angle(120, 60)
~~~

## Simulator practice

Use measured angle moves. Compare the simulated tool positions at 60 and 90 degrees. Check physical binding only on your real attachment.

## On the robot

With the robot off, inspect gear meshing and output travel. If you use the hardware-only homing lines, supervise the first test and keep the duty limit low.

## Check and adjust

Your tool has a documented safe angle range and a known response when it binds. If a tool binds, inspect gearing before stall-based homing.
