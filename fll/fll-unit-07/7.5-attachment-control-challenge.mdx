# Lesson F7.5: Attachment Control Challenge

This challenge brings the drive and attachment together. The simulator checks for a tool move, an outward drive and return home, and no collision. We can use separate route and tool functions to see which part needs adjustment if the yellow target is missed.

## Worked example

`activate_target()` requests a 300 mm approach and a 90 degree tool move followed by its return. The reverse drive requests a return toward home, and the print shows the final motor angle. The distance may need adjustment before the tool is close enough to touch the target.

~~~python
def activate_target():
    robot.straight(300)
    attachment.run_angle(150, 90)
    attachment.run_angle(150, -90)

activate_target()
robot.straight(-300)
print("Tool angle:", attachment.angle())
~~~

## Simulator practice

The yellow target gives the simulator a visible point to approach. A run should move the tool and return home without a collision. If the target stays inactive, the robot's approach position may be worth checking before the tool angle.

## On the robot

Five low-speed physical trials may show whether the robot reaches the target and whether the tool returns to its starting angle. Notes on contact, angle, and home position can separate navigation error from tool error.

## Check and adjust

The simulator's required checks should pass, and the target can be inspected in the field view. If the target is missed on a real mat, compare approach position and tool travel before changing either value.
