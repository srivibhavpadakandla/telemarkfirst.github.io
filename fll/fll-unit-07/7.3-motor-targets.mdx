# Lesson F7.3: Target Angles

Relative angles add to the motor's current position. A target angle instead names a position to reach, which can be useful for an open or closed tool. This lesson sets a zero reference, moves to 90 degrees, and returns to zero. The reference should match a real physical position before the same numbers are used on a robot.

## Worked example

`attachment.reset_angle(OPEN_DEG)` labels the current motor position as zero. The two `run_target()` calls then request closed and open positions. If the tool was not actually open at the reset, the named positions would be misleading.

~~~python
OPEN_DEG = 0
CLOSED_DEG = 90
attachment.reset_angle(OPEN_DEG)
attachment.run_target(180, CLOSED_DEG)
attachment.run_target(180, OPEN_DEG)
~~~

## Simulator practice

The simulator starter shows a relative move. Replacing it with the target calls above should move the tool to 90 degrees and back to zero. A different closed target can be tried after the visible travel is checked.

## On the robot

The physical tool should be at a visible open reference when its angle is reset to zero. Tests without an object can show whether both target positions are clear before a light object is added.

## Check and adjust

Both targets should be reachable without forcing the mechanism. If the same number sends the tool to a different place on later runs, the zero reference or linkage may need checking.
