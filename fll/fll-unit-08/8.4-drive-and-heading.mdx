# Lesson F8.4: Continuous Drive and Heading

Unlike `straight()` and `turn()`, `DriveBase.drive(speed, turn_rate)` starts moving and lets the next line run immediately. The program therefore needs a condition that reaches `robot.stop()`. Here a stopwatch limits the drive to one second, and a heading reading can help us check the direction of the turn.

## Worked example

Speed is in millimeters per second; turn rate is in degrees per second. If DriveBase gyro control is enabled, `robot.reset()` is the appropriate way to reset its angle reference.

~~~python
robot.reset()
watch = StopWatch()
robot.drive(120, 15)
while watch.time() < 1000:
    wait(10)
robot.stop()
print("Heading deg:", hub.imu.heading())
~~~

## Simulator practice

Put the timed drive from the worked example in the editor and predict the curve's direction. The stopped robot and printed heading can then be compared with that prediction.

## On the robot

A clear area and reduced speed should be used for the first physical run. A floor mark can show whether the hub's heading agrees with the visible turn.

## Check and adjust

The run should end after about one second, with a heading sign consistent with the turn direction. If it keeps moving, inspect the loop condition and stop call before another attempt.
