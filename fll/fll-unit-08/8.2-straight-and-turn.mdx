# Lesson F8.2: Straight and Turn Segments

A route of straight and turn segments is easier to measure because each command finishes before the next begins. Use a negative distance to reverse and a negative angle to turn left, then read the final heading. If the route misses, locate the first segment that diverged before editing a later command.

## Worked example

~~~python
robot.reset()
robot.straight(300)
robot.turn(90)
robot.straight(50)
print("Distance mm:", robot.distance())
print("Angle deg:", robot.angle())
~~~

## Simulator practice

Mark the expected corner and final point. Run Step and find the first mismatch.

## On the robot

Place tape at each corner. Measure the first error before changing a later segment.

## Check and adjust

If the endpoint misses, use the route log to identify the first segment that diverged, then retest that segment on its own.
