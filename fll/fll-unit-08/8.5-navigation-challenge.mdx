# Lesson F8.5: Navigation Challenge

This challenge brings measured straights and turns into one navigation route. The robot should cross the practice line, make two turns, and return home. Recording the landmarks along the way can show where a calibration profile changes the result; an arc can be considered after the segmented route works.

## Worked example

The function follows the outgoing route in reverse to return. The final heading print gives one more observation, but home position and obstacle clearance still need to be checked in the field view.

~~~python
def cross_line_and_return():
    robot.straight(850)
    robot.turn(90)
    robot.straight(50)
    robot.straight(-50)
    robot.turn(-90)
    robot.straight(-850)

cross_line_and_return()
print("Heading:", hub.imu.heading())
~~~

## Simulator practice

Run from the fixed home pose and compare the line crossing, turns, and final position with the plan. The automatic profile table can reveal which landmark is missed first under a different calibration.

## On the robot

The tool should be installed while tracing the route on the mat. Marked corners and moderate speed can make a clearance or turn error easier to locate.

## Check and adjust

A successful run should cross the line and return without a collision. For any profile that fails, record its first missed landmark before changing a later segment.
