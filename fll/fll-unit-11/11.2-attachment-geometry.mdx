# Lesson F11.2: Plan Attachment Clearance

An attachment changes the space the robot needs along a route. Even if the chassis clears an obstacle, the tool may reach into it while opening or closing. This lesson uses a named clearance distance for the approach, then checks the tool's full sweep around the target.

## Worked example

The approach stops short by `TOOL_CLEARANCE_MM` before the tool moves. The number is an example; the real margin should come from the attachment's reach and a field measurement.

~~~python
TOOL_CLEARANCE_MM = 70
target_gap_mm = 400
approach_mm = target_gap_mm - TOOL_CLEARANCE_MM
robot.straight(approach_mm)
attachment.run_angle(160, 60)
~~~

## Simulator practice

Use the worked example's clearance value for a first approach, then compare the tool at each end of its travel. The field view can show whether the approach leaves room near the yellow target.

## On the robot

Tracing the widest tool position on paper can help estimate its swept space. A slow physical test should then measure the closest gap with the actual tool installed.

## Check and adjust

The gap should remain positive through the whole tool motion. If contact occurs, measuring the full sweep can show whether the margin or route needs changing.
