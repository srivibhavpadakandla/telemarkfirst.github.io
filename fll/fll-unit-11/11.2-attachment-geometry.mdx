# Lesson F11.2: Plan Attachment Clearance

An attachment changes the robot's effective width and forward reach, so a route that cleared an obstacle without the tool may collide afterward. Measure the tool's sweep at its open and closed angles, then add a named clearance margin that can be adjusted after a field test.

## Worked example

~~~python
TOOL_CLEARANCE_MM = 70
target_gap_mm = 400
approach_mm = target_gap_mm - TOOL_CLEARANCE_MM
robot.straight(approach_mm)
attachment.run_angle(160, 60)
~~~

## Simulator practice

Run the approach with the tool at both ends of its travel. Check clearance around the yellow target.

## On the robot

Trace the tool's widest position on paper. Test the route with the actual tool installed and measure the closest gap.

## Check and adjust

The planned clearance remains positive throughout the tool motion. If the tool strikes a model, measure its full swept width.
