# Lesson F11.3: Choose a Mission Program

When a match uses more than one launch, the team needs a reliable way to choose the intended mission. The simulator can use a mission name variable; Pybricks Code provides five Prime Hub program slots. We will compare named routes and connect each physical slot with a launch mark and attachment.

## Worked example

The `if` and `elif` branches run different routes for two known names. Any other name prints a message, and the final stop call still runs.

~~~python
MISSION = "target"

if MISSION == "target":
    robot.straight(300)
    attachment.run_angle(160, 60)
elif MISSION == "line":
    robot.straight(700)
else:
    print("Unknown mission")
robot.stop()
~~~

## Simulator practice

Use the worked example's `MISSION` branches, changing the name to each known value and then an unknown one. The printed message and robot motion should make the selected branch clear.

## On the robot

Two small programs can be saved in separate hub slots. A table linking each slot to its attachment and launch mark can help the team choose correctly at the field.

## Check and adjust

A teammate should be able to choose the intended route from the slot labels and launch plan. If another route runs, check the selected slot or mission name before changing movement values.
