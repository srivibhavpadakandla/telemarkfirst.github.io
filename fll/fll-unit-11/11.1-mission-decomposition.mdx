# Lesson F11.1: Break a Mission into Actions

A complete mission has several parts: leaving home, approaching a model, acting, checking the result, and returning. We can give each part a function so a missed target can be traced to a smaller piece of the route. This lesson starts with an approach, a tool action, and a return.

## Worked example

The distance is passed to both movement functions, so the return is the same length as the approach. A real mission may need a different return path if the outgoing path is blocked.

~~~python
def approach_target(distance_mm):
    robot.straight(distance_mm)

def activate():
    attachment.run_angle(180, 90)
    attachment.run_angle(180, -90)

def return_home(distance_mm):
    robot.straight(-distance_mm)

approach_target(300)
activate()
return_home(300)
~~~

## Simulator practice

Put the worked example's functions in the editor, then run each from a known pose before combining them. The first function that misses its planned position can then be adjusted without changing the others.

## On the robot

A route diagram with the function names can help a teammate connect code to field positions. Testing one function from a marked start may reveal an assumption about launch alignment.

## Check and adjust

For each function, record where the robot should start and what visible result should follow. If the full route fails, the first mismatching result gives a focused place to retest.
