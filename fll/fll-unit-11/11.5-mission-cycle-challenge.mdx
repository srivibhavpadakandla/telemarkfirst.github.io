# Lesson F11.5: Mission Cycle Challenge

This challenge combines a target action, a delivery, and a return in one cycle. Separate functions can make the route easier to test, while time readings can show which action takes the longest. The worked example covers a target action and return, so the delivery step still needs to be planned and added.

## Worked example

The stopwatch measures from the start of the program. `target_step()` moves the attachment, and `return_step()` goes back after a half turn; neither function verifies that an object was delivered.

~~~python
watch = StopWatch()

def target_step():
    robot.straight(300)
    attachment.run_angle(180, 90)
    attachment.run_angle(180, -90)

def return_step():
    robot.turn(180)
    robot.straight(300)

target_step()
print("Target ms:", watch.time())
return_step()
print("Total ms:", watch.time())
~~~

## Simulator practice

Add a delivery step for the generic field, then compare target, delivery, and home results over three attempts. The total time can be recorded alongside each result.

## On the robot

The physical route should use the actual tool. A marked point for a short return can help if the pickup fails before delivery.

## Check and adjust

The completed route should attempt both objectives and end at home within the time budget. If it misses, separate trials may reveal which action first changed the planned pose.
