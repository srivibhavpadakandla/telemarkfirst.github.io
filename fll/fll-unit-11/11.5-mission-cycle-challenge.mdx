# Lesson F11.5: Mission Cycle Challenge

Complete a target action and object delivery in one cycle, then return home. Keep the actions in separate functions and print elapsed time after each, testing both functions alone before the full route. Prepare a short return if the first action fails.

## Worked example

~~~python
watch = StopWatch()

def target_step():
    robot.straight(300)
    attachment.run_angle(180, 90)
    attachment.run_angle(180, -90)

def return_step():
    robot.turn(180)
    robot.straight(300)

target_step()
print("Target ms:", watch.time())
return_step()
print("Total ms:", watch.time())
~~~

## Simulator practice

Use the generic target and delivery zones. Record the total time and home position in three attempts.
