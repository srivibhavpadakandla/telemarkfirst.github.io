# Lesson F0.M2: What Simple Machines Do

The sketch from the previous lesson may include a lever, axle, or ramp. These are simple machines: they change how an applied force reaches a load. A longer input movement can produce a stronger push over a shorter distance, but the mechanism does not create energy. This lesson compares the six common types so we can recognize them in a mission tool.

| Simple machine | What it does | LEGO robot example |
| --- | --- | --- |
| **Lever** | Rotates around a pivot to move a load | A short arm lifts a handle. |
| **Wheel and axle** | Turns an axle and wheel together | Drive wheels move the robot; a gear fixed to an attachment axle passes rotation along. |
| **Pulley** | Guides a string or changes its pulling direction | A string routed over a pulley raises a light object. |
| **Inclined plane** | Spreads a lift over a longer path | A ramp guides an object upward. |
| **Wedge** | Pushes things apart or guides them sideways | A tapered guide centers an object as the robot approaches. |
| **Screw** | Turns rotation into travel along a thread | A threaded LEGO part can move a small piece gradually. |

Gears can change speed, turning direction, or torque between axles. A robot attachment may combine a motor, gears, an axle, and a lever. The table gives possible starting ideas; a test with the field model will show which motion is useful.

## Hands-on practice

A beam on a pivot makes a small lever. Moving the pivot closer to one end may change how far the other end travels for the same input. A wheel fixed to an axle should turn with it. Drawing an input and output arrow for each build can help you see the difference. A ruler on a pencil and a cardboard circle on a pencil can stand in for these two builds if LEGO parts are unavailable.

## Check and adjust

For each build, identify the simple machine and describe what changed in the motion or force. If it slips or binds, the pivot or axle supports may need attention before a motor would help.
