# Lesson F0.1: What Is FLL?

In FIRST LEGO League Challenge, the robot starts in a home area and runs without a driver during the Robot Game. We can use a short route to see how a program changes its position on the practice field. The aim here is to return to home after a drive and turn, then compare that simulated route with the current season's field rules.

## Worked example

The [course port map](/fll/python-starter) is already loaded in the simulator editor. In this example, the robot drives away from home, turns around, and drives the same programmed distance back. On a physical build, the ports and dimensions would need to match your robot.

~~~python
print("Robot Game practice")
robot.straight(200)
robot.turn(180)
robot.straight(200)
~~~

## Simulator practice

The starter makes a short measured move. Watching its start and final pose can help you connect each code line with a field movement. After adding a return, the blue home area gives you a place to check whether the route ended where you expected.

## On the robot

The current [FIRST season materials](https://www.firstinspires.org/resources/library/fll/season-materials) should guide any physical Robot Game plan. Tracing this route from a chosen launch position without a tool can show whether the return would fit inside home on your field.

## Check and adjust

The program determines the robot's moves, while the current rulebook determines what scores. If the final pose misses home, the first segment that differs from the plan may show where to adjust a distance or turn.

Reference: [FIRST season materials](https://www.firstinspires.org/resources/library/fll/season-materials).
