# Lesson F0.M3: Read Missions as Machines

Mission descriptions tell you the goal. The field model tells you **which physical change** is needed. Treat each mission as a motion problem before choosing an attachment. The model itself and the robot's tool may each use one or more simple machines.

| If the model must... | Look for... | First mechanism to try |
| --- | --- | --- |
| Rotate a handle | Its pivot and required turning direction | A short lever on the robot that pushes the handle. |
| Raise a light piece | The lifting point and required height | A lever arm, or a string and pulley when the route allows it. |
| Slide an object into an area | The object's path and contact surface | A broad pusher, possibly with a wedge shaped guide. |
| Roll or carry an object | How it is held and released | Wheels and axles for approach, plus a small gate or lever for release. |

These are **candidate ideas**, not claims about a particular season's missions. Read the current [FIRST Robot Game materials](https://www.firstinspires.org/resources/library/fll/season-materials) and inspect the actual model before deciding what is legal or scores.

## Mission breakdown

Choose one model and fill in this sentence: “The robot applies **[push, pull, or rotation]** at **[contact point]**, so **[part]** moves **[distance or angle]** toward **[goal]**.” Sketch the model's pivot, path, and any obstacles. Circle the simple machine already present in the model, then name one the robot could use to activate it.

## Check and adjust

Test the motion gently by hand. If the model moves in a different direction than your sketch predicts, revise the sketch before building a tool.
