# Lesson F0.M3: Read Missions as Machines

Now that we can recognize simple machines, we can look for them in a mission model. The mission description gives the scoring goal, while the model shows the movement needed to reach it. Before choosing an attachment, study both the model itself and the robot's tool: identify the part that must move, its path, and a place where the tool could apply force.

| If the model must... | Look for... | First mechanism to try |
| --- | --- | --- |
| Rotate a handle | Its pivot and required turning direction | A short lever on the robot that pushes the handle. |
| Raise a light piece | The lifting point and required height | A lever arm, or a string and pulley when the route allows it. |
| Slide an object into an area | The object's path and contact surface | A broad pusher, possibly with a wedge shaped guide. |
| Roll or carry an object | How it is held and released | Wheels and axles for approach, plus a small gate or lever for release. |

The mechanisms in the table are starting ideas. The current [FIRST Robot Game materials](https://www.firstinspires.org/resources/library/fll/season-materials) and the actual field model determine which actions are allowed and which ones score.

## Mission breakdown

For one model, describe the action in a sentence: “The robot applies [push, pull, or rotation] at [contact point], so [part] moves [distance or angle] toward [goal].” A sketch of the pivot, path, and nearby obstacles may reveal where a simple tool could make that action happen.

## Check and adjust

A gentle hand test should show whether the model moves in the direction your sketch predicts. If it moves another way or stops early, the sketch may need to change before you build a tool.
