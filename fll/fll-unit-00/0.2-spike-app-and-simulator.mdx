# Lesson F0.2: Set Up Pybricks

The simulator can run the course's Python starter before a physical robot is ready. Pybricks Code runs a program on the SPIKE Prime Hub after Pybricks firmware is installed. This lesson lets us compare the two environments and identify the wiring and dimensions the starter assumes.

The course setup uses drive motors on ports A and B, a color sensor on C, an ultrasonic sensor on D, and an optional tool motor on E. Those ports and motor directions should match the real build. A program saved in Telemark stays in the browser; a Pybricks hub slot is a separate copy.

## Worked example

The simulator editor already includes the course setup. The code below creates the hub, motors, sensors, and DriveBase before requesting a 100 mm drive. The 56 mm wheel diameter and 112 mm axle track are starter values that may need to change for a physical robot.

~~~python
from pybricks.hubs import PrimeHub
from pybricks.pupdevices import Motor, ColorSensor, UltrasonicSensor
from pybricks.parameters import Port, Direction
from pybricks.robotics import DriveBase

hub = PrimeHub()
left_motor = Motor(Port.A, Direction.COUNTERCLOCKWISE)
right_motor = Motor(Port.B)
robot = DriveBase(left_motor, right_motor, wheel_diameter=56, axle_track=112)
color_sensor = ColorSensor(Port.C)
distance_sensor = UltrasonicSensor(Port.D)
robot.straight(100)
~~~

## Simulator practice

The starter should move 100 mm in the simulator. A second run with `robot.straight(150)` can show how a 50 mm change affects the final position. Resetting between runs gives both versions the same start.

## On the robot

Installing Pybricks changes the hub firmware, so the [Pybricks installation guide](https://pybricks.com/learn/getting-started/install-pybricks/) should be followed with a mentor. The guide also explains how to restore LEGO firmware. For an initial motor test, the robot should have its wheels lifted and its ports checked against the program.

## Check and adjust

You should be able to name the course port map and tell which copy of the program is in Telemark and which is on the hub. If the hub does not connect, firmware and Bluetooth permissions are useful first checks.

Reference: [Pybricks installation guide](https://pybricks.com/learn/getting-started/install-pybricks/).
