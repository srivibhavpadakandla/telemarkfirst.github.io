# Lesson F0.5: Precision Route Challenge

We have driven measured distances and made measured turns. This challenge combines them in a route that crosses the dark practice line and returns to the blue home area. The simulator checks for a line crossing, a turn, and a return without collision.

## Worked example

The 850 mm drive should cross the practice line in this simulator. A 180 degree turn points the robot back toward home, and the second drive requests the same distance in that direction. The numbers are a starting route to test, not measurements for a physical robot.

~~~python
robot.straight(850)
robot.turn(180)
robot.straight(850)
~~~

## Simulator practice

The field view can show where the robot first crosses the line and where it ends after the return. If the example misses home, changing one distance or turn at a time can help identify the cause. Resetting between attempts keeps the starting pose the same.

## On the robot

The same launch marks should be used for three physical trials. Measuring the final offset from the home target each time can show whether the route is close and repeatable enough to keep testing.

## Check and adjust

The simulator checks should confirm a line crossing, a measured turn, and a return home. On the mat, three recorded final positions may reveal a turn that needs separate testing from a marked heading.
