# Lesson F0.5: Precision Route Challenge

Plan a route that crosses the practice line and returns home using measured distances and angles. Mark each segment in millimeters and each turn in degrees before coding, then test the route one segment at a time. A repeatable return matters more than a longer route that works only once.

## Worked example

~~~python
robot.straight(850)
robot.turn(180)
robot.straight(850)
~~~

## Simulator practice

Edit the route to cross the dark line and finish in the blue home region. Use Reset between attempts and record each result.

## On the robot

Run the route from the same launch marks three times. Measure the final offset from your home target after each run.

## Check and adjust

The robot crosses the line, returns to home, and your notes show three trial outcomes. If the route fails after a turn, test that turn alone from a marked heading.
