# Lesson F0.M1: Design with Simple Machines

Before choosing LEGO pieces or writing code, describe **what must move**. A mission mechanism can be understood as a few simple machines working together. Look for an input (the robot's push or a motor's rotation), a change in motion or force, and an output (the mission model moves into its target position).

For example, a motor turns an axle, the axle turns a short arm, and the arm pushes a model's handle. The axle and arm are familiar building blocks. You do not need to invent an entirely new kind of machine for every mission.

## Try the design lens

Pick a practice mission model or make a small target from LEGO pieces. Without building an attachment yet:

1. Draw the model's **start** and **goal** positions.
2. Add an arrow for the motion needed: push, pull, lift, rotate, or release.
3. Mark where the robot can touch it and which way the robot or motor can apply force.
4. Sketch the smallest tool that could turn that input into the needed motion.

If your sketch has many moving parts, ask which single motion actually earns the result. Start with that motion and add parts only when a test shows a need.

## Check and adjust

Explain your sketch to a teammate using the words **input**, **motion**, and **output**. They should be able to point to the part that touches the mission model and predict what moves when the robot acts.
